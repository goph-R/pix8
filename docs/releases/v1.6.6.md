# Pix8 1.6.6 — first desktop release

Pix8 is a 256-color indexed pixel art editor built around VGA-era workflows:
one shared 256-entry palette for the whole document, independent layers,
frame animation, and a GrafX2-style palette editor.

This is the **first release you can install and run offline**. It's the same
editor as [pix8.app](https://pix8.app), running as a native window with real
Open/Save dialogs instead of browser downloads.

## Downloads (Windows, 64-bit)

| **Pix8.1.6.6.exe** | 82.2 MB | Portable — single file, runs without installing |

Requires Windows 10 or later (x64). The browser version stays available at
pix8.app and needs no download.

## ⚠️ These builds are not signed yet

Windows will show a **"Windows protected your PC"** SmartScreen warning on
first run. To continue: click **More info**, then **Run anyway**.

Code signing is planned for a future release. Until then, you can verify your
download matches what was published by checking its SHA-256:

```
Pix8.1.6.6.exe        934cdf2f4002f77e2427e6299a61861e6fce19052360a086d51cb9be08f3068c
Pix8.Setup.1.6.6.exe  6b20c7b4cbedd42a2de9d1d7ffe58a37578e3f31c7294dea8b1776f38253f0cd
```

In PowerShell: `Get-FileHash Pix8.Setup.1.6.6.exe -Algorithm SHA256`

## Fixed in this version

- **Typing works again after closing a dialog.** Removing a dialog while it
  still held focus left the focus state wedged — the next inline input (tab
  rename, layer rename) looked focused but showed no caret and silently
  dropped typed characters.
- **Typing works again after a native file dialog**, which had the same
  dead-input symptom in the desktop build.
